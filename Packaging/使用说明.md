# 记忆坞 1.0

本地记忆工具，包含 macOS 桌面版与 DeepSeek Harness 插件版。

## 安装桌面版

把「记忆坞.app」拖进 Applications 文件夹，然后双击打开。首次启动会在 `~/Documents/记忆坞` 创建示例工作区，并显示珊瑚色悬浮球。

- 单击悬浮球：打开/收起记忆面板
- 把记忆卡拖到任意 AI 输入框：交付记忆内容
- 按住 `⌥ Option` 拖拽：拖出纯文本
- 右键悬浮球：打开工作区、设置、退出

## 安装 DSH 插件版

打开 DeepSeek Harness → 插件 → 添加本地插件，选择 `dsh-plugin` 文件夹；也可以在终端使用当前 DSH profile 执行：

```bash
dsh plugin --profile desktop add link:/path/to/dsh-plugin
```

插件安装后，DSH Web 界面右下角会出现记忆悬浮球：

- 点击记忆卡：插入当前输入框
- 拖动记忆卡：按纯文本拖到输入框或其他应用
- 顶部 `⚙` 查看/选择记忆工作区
- Agent 可使用 `memory_dock` 工具读取记忆

## 工作区

默认目录：`~/Documents/记忆坞`

一级文件夹就是分类。直接放入 `.md`、`.txt`、`.json`、`.pdf`、`.docx` 等文件后，面板会自动刷新。记忆文件完全保存在本地。
